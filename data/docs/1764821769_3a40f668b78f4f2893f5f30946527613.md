# 员工年假与请假管理制度

## 1. 目的
为规范公司员工年假与请假管理，保障员工合法权益，维护公司正常工作秩序，特制定本制度。

## 2. 适用范围
本制度适用于公司全体正式员工。

## 3. 年假管理

### 3.1 年假天数
- 员工入职满1年不满10年的，年休假5天
- 员工入职满10年不满20年的，年休假10天
- 员工入职满20年的，年休假15天

### 3.2 年假申请流程
1. 员工提前至少3个工作日提交《年假申请表》
2. 部门负责人审批
3. 人力资源部审核并备案
4. 员工休假前做好工作交接

### 3.3 年假使用规定
- 年假可分次使用，但每次不少于1天
- 年假应在当年12月31日前使用完毕，逾期未使用的自动作废
- 员工离职时，未休年假按国家规定给予相应补偿

## 4. 请假管理

### 4.1 请假类型
- 病假：员工因病需要休息的假期
- 事假：员工因个人原因需要处理私事的假期
- 婚假：员工结婚享受的假期，一般为3天
- 产假：女员工生育享受的假期，按国家规定执行
- 陪产假：男员工配偶生育享受的假期，一般为15天

### 4.2 请假审批流程
1. 员工提交《请假申请表》及相关证明材料
2. 部门负责人审批
3. 人力资源部审核并备案

### 4.3 请假薪资规定
- 病假：按公司规定发放病假工资
- 事假：事假期间不发放工资
- 婚假、产假、陪产假：按国家规定发放工资

## 5. 附则
- 本制度由人力资源部负责解释
- 本制度自发布之日起执行
